# Security and privacy contact

This repository does not contain the production source code or operational secrets for Frikiando.

If you identify a security or privacy concern related to the product, please report it privately to [zorapp.dev@gmail.com](mailto:zorapp.dev@gmail.com). Do not publish personal data, credentials, access tokens or exploit details in a public issue.

Reports should include a concise description, the affected product area, reproduction steps when safe, and any relevant device or Android version information.
